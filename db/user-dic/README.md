# mecab-ko-dic 사용자 사전

이 폴더의 `*.csv` 는 `db/Dockerfile` 빌드 시 mecab-ko-dic 의 `user-dic/` 에 복사되어 `tools/add-userdic.sh` 로 사전에 합쳐진다.
형태소 분석기가 모르는 외래어·IT 용어가 `에스 · 커 · 레이 · 션` 처럼 조각나는 것을 막는 용도다.

## 형식 (13개 필드, 쉼표 구분)

```
표층형,,,,품사,*,종성유무,읽기,*,*,*,*,*
에스컬레이션,,,,NNG,*,T,에스컬레이션,*,*,*,*,*
카프카,,,,NNP,*,F,카프카,*,*,*,*,*
```

- 2~4열(문맥 ID·비용)은 비워 둔다. `add-userdic.sh` 가 채운다.
- 품사: 일반명사 `NNG`, 고유명사(제품·회사명) `NNP`.
- 종성 유무: 마지막 글자에 받침이 있으면 `T`, 없으면 `F`.

## 등록 기준

- 조각이 의미 없는 단어(에스컬레이션, 쿠버네티스, 임베딩)는 넣는다.
- 조각이 각각 의미 있는 복합어(체크리스트 → 체크·리스트, 백로그 → 백·로그)는 넣지 않는다. 등록하면 통째로만 검색된다.
- 검색할 때 어떤 단위로 칠지를 기준으로 판단한다. `스마트팩토리` 를 등록하면 `스마트` 로는 더 이상 걸리지 않는다.

## 적용 절차

1. CSV 를 고친다.
2. `cd db && ./run.sh` 로 이미지를 다시 빌드한다 (볼륨은 유지된다).
3. 이미 색인된 키워드 색인은 옛 사전으로 만든 값이므로 다시 계산한다 (임베딩은 영향 없음):
   `sudo docker exec -i confluence-kb-postgres psql -U postgres -d confluence_kb -c "UPDATE chunks SET content = content"`
4. 확인: `select to_tsvector('korean', '에스컬레이션 쿠버네티스')` 가 통째로 나오면 된다.
